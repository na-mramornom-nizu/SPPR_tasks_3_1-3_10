# Упражнения 3.1–3.10. Смешанная целочисленная оптимизация

Работа по дисциплине «Системы поддержки принятия решений» на основе главы 3 предоставленного пособия `milo.pdf` (упражнения на с. 135–140).

Ноутбук [`SPPR_tasks_3_1-3_10.ipynb`](SPPR_tasks_3_1-3_10.ipynb) содержит исходные условия, данные, математические модели, решения на Pyomo/HiGHS и ответы ко всем десяти упражнениям и их подпунктам. Рассматриваются покрытие, судоку, выбор проектов, производство с фиксированными затратами, размещение служб, приготовление блюд, логарифмическая линеаризация, логические связи и оптовые скидки.

Числа, отсутствующие в пособии, заданы как воспроизводимые учебные примеры и отмечены в разделах «Дано». Судоку и равенство из упражнения 3.8 взяты из источника. Пропуск в исходном тексте 3.4 и допущение о дискретных закупках в примере 3.10 указаны явно.

## Запуск

Проверено на Python 3.12. Установите зависимости в отдельное виртуальное окружение:

```bash
python -m pip install pyomo highspy numpy pandas matplotlib jupyterlab
python -m jupyter lab SPPR_tasks_3_1-3_10.ipynb
```

В JupyterLab выберите **Kernel → Restart Kernel and Run All Cells**. Используется `appsi_highs` с переходом к `highs` или установленному CBC при необходимости. Численные результаты и графики сохранены в ноутбуке; для выполнения исходный PDF и доступ к сети не требуются. Время решения в сравнении моделей зависит от компьютера, решателя и его версии.
